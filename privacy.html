プライバシーポリシー

最終更新日：2026年11月2日

「きょうの仏教」（以下「本アプリ」）は、利用者のプライバシーを尊重し、個人情報の保護に努めます。本ポリシーは、本アプリにおける情報の取り扱いについて説明するものです。

本アプリの運営者は、個人開発者の Seiya Sugimoto です（本ポリシーでは「当社」または「開発者」といいます）。連絡先はサポートページに記載しています。

本アプリは、毎日のエピソード閲覧・お気に入り・検索・通知について、個人情報を収集しません。これらの機能はインターネット接続がなくてもご利用いただけます。「AI相談」機能をご利用いただく場合に限り、相談内容の本文を外部サーバーへ送信します（4章）。また、AI相談の利用可能回数を判定するため、購読状態の確認に伴う通信が発生します（5章）。

1. 収集する情報

本アプリは、氏名、メールアドレス、電話番号などご本人を特定できる情報を取得しません。アカウント登録やログイン機能もありません。

以下の機能に限り、外部サービスと通信します。それぞれの詳細は各章をご覧ください。

  • 「AI相談」機能：相談内容の本文を、エピソードを選ぶために外部サーバーへ送信します（4章）
  • 「AI相談」のサブスクリプション：購読状態の管理のため、購入情報を課金基盤の事業者と共有します。この確認は、購読の有無にかかわらず行われます（5章）

上記以外の機能（毎日のエピソード閲覧、お気に入り、本文の検索、通知）は、いずれもインターネット接続を必要とせず、これらの機能のために情報を外部へ送信することはありません。いずれの場合も、位置情報・連絡先・写真・カレンダーなどの端末内データ、広告識別子（IDFA）、利用状況の解析データは取得しません。

2. 端末内に保存されるデータ

本アプリでは、以下のデータを利用者の端末内のデータベースにのみ保存します。これらは本アプリの動作にのみ使用され、開発者がこれらのデータを外部から閲覧することはできません。

  • エピソードの既読状態・お気に入り
  • ♡（響いた話）とひとことメモ、以前のバージョンで「今日の問い」に答えた記録。外部へは送信せず、AI相談にも使いません。メモはアプリ内から削除できます。メモに自傷・自殺をほのめかす言葉が含まれていても、メモは書いたとおり端末内に保存され、同じ画面に相談窓口をご案内します。この判定は端末内で行い、外部へは何も送信しません
  • 通知の時刻・ON/OFF、アプリの表示言語などの設定内容
  • AI相談の履歴（相談した内容とAIからの回答）。アプリ内からいつでも削除できます
  • AI相談の利用回数を管理するための識別子（端末内で生成した乱数。詳細は4章）

これらのデータは、本アプリをアンインストールすると端末から削除されます。

表示言語は、アプリ内の「設定」で日本語と英語を切り替えられます。切り替えても上記のデータは削除されず、外部へ送信されることもありません。

3. コンテンツについて

本アプリが配信するエピソード本文・画像は、すべてアプリ内にあらかじめ収録されたものであり、外部のサーバーから取得することはありません。毎日のエピソード閲覧・お気に入り・本文検索・通知の利用にインターネット接続は必要ありません。

4. AI相談機能について

「AI相談」は、利用者が入力した悩みに対し、収録済みの100話の中から関連する1話を提示する機能です。この機能をご利用いただく場合に限り、以下の情報を外部に送信します。

送信される情報

  • 利用者が入力した相談内容の本文
  • 利用回数を管理するための識別子（端末内で生成した乱数。氏名・メールアドレス・電話番号などとは結びついていません）
  • アプリの表示言語（日本語または英語）。英語で使っている場合は、英語で読める話の番号の一覧もあわせて送信し、その中から話を選びます

このほか、インターネットを使う通信ではいつもそうであるように、送信先の事業者には IP アドレスなどの接続に関する情報が届きます。

送信先

  • Cloudflare, Inc.（中継サーバー）
  • OpenAI, L.L.C.（エピソードの選定および文章の生成）

送信の目的

収録されている100話の中から、利用者の状況に近い話を選び、つながりを説明する短い文章を作成するためにのみ使用します。

当社での保存について

送信された相談内容を、当社が管理するサーバーに保存することはありません。相談の記録は利用者の端末内にのみ保存され、アプリ内からいつでも削除できます。

AI相談の利用回数を数えるため、中継サーバー（Cloudflare）には、端末内で生成した識別子と、その月の利用回数だけを記録します。この記録に相談の内容は含まれず、約40日で自動的に削除されます。この記録は、氏名などと結びつかない仮名の情報です。

相談を送るたびに、中継サーバーはこの識別子を使って RevenueCat, Inc. に購読状態を問い合わせ、その月に使える回数を判定します。

外国にある事業者への送信

送信先の3社（Cloudflare, Inc. / OpenAI, L.L.C. / RevenueCat, Inc.）は、いずれもアメリカ合衆国の事業者で、送信した情報は同国を含む各社の拠点で取り扱われます。アメリカ合衆国の個人情報の保護に関する制度は、個人情報保護委員会が「外国における個人情報の保護に関する制度等の調査」として公表している情報（アメリカ合衆国の項）をご覧ください。各社は、それぞれのプライバシーポリシーや利用条件に基づいて、送信された情報を保護する措置を講じています。AI相談の初回にこの送信について同意をいただいた場合にのみ送信します。

OpenAI での取り扱い

OpenAI が公表している API の方針では、API を通じて送信されたデータは、利用者（当社）が明示的に共有を選んだ場合を除き、OpenAI のモデルの学習や改善には使われません。また OpenAI は、不正利用の監視のための記録を最長30日間保持することがあり、法令で求められる場合や、サービスや第三者を害から守るために合理的に必要な場合はそれより長く保持することがあるとしています。詳しくは OpenAI の API データの取り扱いに関する説明（英語）をご覧ください。

ご利用にあたって

AI相談機能の初回利用時に、上記について確認する画面を表示し、同意をいただいた場合のみ送信します。同意されない場合、AI相談機能はご利用いただけませんが、その他の機能（毎日のエピソード・お気に入り・検索・通知）はこれまで通りご利用いただけます。

自傷・自殺に関する内容が含まれる場合

入力内容に自傷・自殺をほのめかす表現が含まれると端末内で判定した場合、外部への送信は行わず、その場で公的な相談窓口をご案内します。該当した内容は、端末内の履歴にも保存されません。

アプリを日本語で使っている場合は国内の公的な相談窓口を、英語で使っている場合は国・地域に応じた相談窓口と緊急番号をご案内します（詳しくは英語版のプライバシーポリシーの4章）。

5. AI相談プラン（サブスクリプション）について

AI相談は無料で毎月3回までご利用いただけます。回数は日本時間の毎月1日にリセットされます。それ以上ご利用いただく場合、自動更新サブスクリプション（AI相談プラン）へのご登録が必要です。

ご購入いただく際の決済はApple社が処理し、お支払い情報（クレジットカード番号など）を当社が取得することはありません。購読状態の管理のため、RevenueCat, Inc. のサービスを利用しており、購入に関する情報（購読の有無・期限、購入の履歴など）が同社と共有されます。

AI相談の利用可能回数は購読状態によって変わるため、本アプリは購読されていない場合も、アプリの起動時および購読プランの画面を開いたときに、RevenueCat, Inc. へ購読状態を問い合わせます。このとき、本アプリに組み込んだ RevenueCat のソフトウェア（SDK）は、4章に記載した端末内で生成した識別子（乱数）とあわせて、購読の管理に必要な端末と購入の情報（端末の機種、OS とアプリのバージョン、言語・地域の設定、App Store の国、Apple が開発者ごとに割り当てる端末の識別子〔IDFV〕、購入の記録など）を送信します。広告識別子（IDFA）は送信しません。これらは氏名・メールアドレス・電話番号などとは結びついていません。

また、購入の手続きは Apple が行うため、購入の際には Apple にも必要な情報が送信されます。いずれの通信でも、送信先の事業者には IP アドレスなどの接続に関する情報が届きます。

6. 通知について

本アプリの通知は、すべて端末内で生成・管理されるローカル通知です。外部のサーバーを経由するプッシュ通知は使用していません。通知の許可はいつでも端末の「設定」アプリから変更できます。

7. 外部リンクについて

本アプリには、以下の外部サイトへのリンクが含まれます。リンク先サイトにおける情報の取り扱いについては、各サイトのプライバシーポリシーをご確認ください。

  • 公的な相談窓口（自傷・自殺に関する内容を検知した場合に表示）
  • 本プライバシーポリシーおよび利用規約
  • Apple のサブスクリプション管理ページ（設定の「サブスクリプションを管理・解約」から開きます）
  • お問い合わせ先のメールアドレス（設定の「お問い合わせ」から開くサポートページに記載）

8. 第三者への提供

本アプリは、ご本人を特定できる情報（氏名・メールアドレス・電話番号等）を収集していないため、これらを第三者に提供することはありません。AI相談機能・サブスクリプションのご利用に伴い、4章・5章に記載の範囲で外部サービス提供者（Cloudflare, Inc. / OpenAI, L.L.C. / RevenueCat, Inc.）と情報を共有しますが、それ以外の第三者への提供は行いません。

9. 子どものプライバシー

本アプリはアカウント登録を必要とせず、ご本人を特定できる情報も収集しません。毎日のエピソード・お気に入り・検索・通知は、年齢を問わずご利用いただけます。

AI相談は、入力した文章を外部の事業者に送信するため、13歳以上の方を対象とします。18歳未満の方は、保護者の方の同意を得てご利用ください（送信先の OpenAI の利用条件に合わせています）。

13歳未満の方がAI相談を使ったことが分かった場合でも、当社の側に残るのは4章の利用回数の記録だけで、これは約40日で自動的に削除されます。相談の内容は当社のサーバーに保存されません。

10. 利用者の選択と権利

AI相談の相談内容は、利用者の同意に基づいて送信します。同意はアプリ内の「設定」→「AI相談の同意設定」からいつでも取り消すことができ、取り消した後は送信しません。購読状態の確認は、利用者が選んだサブスクリプションを提供するために行います。

当社のサーバーに残るのは、4章に記載した仮名の利用回数の記録だけです。端末内のデータ（AI相談の履歴・メモ・♡など）は、アプリ内で削除するか、アプリをアンインストールすることで、利用者ご自身で削除できます。

利用回数の記録は、個別に削除することが技術的にできません。識別子はアプリの画面に表示されず、ご本人とも結びついていないため、お問い合わせをいただいても、どの記録がその方のものかを当社が特定できないためです。この記録は約40日で自動的に削除されます。
